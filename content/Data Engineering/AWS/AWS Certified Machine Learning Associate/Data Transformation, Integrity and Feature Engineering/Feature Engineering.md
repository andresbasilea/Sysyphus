
### Feature engineering
- Applying your knowledge of the data (and model you are using) to create better features to train your model with.

### Curse of Dimensionality
- Too many features can be a problem - leads to sparse data
- Every feature is a new dimension
- Much of feature engineering is selecting the features most relevant to the problem at hand
	- this is where domain knowledge comes into play
- You can also use unsupervised dimensionality reduction techniques like PCA or K-Means.
