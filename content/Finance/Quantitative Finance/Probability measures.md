There are subsets that cannot be measured. We focus on studying those who are measurable (**sigma algebra**).

A **sigma algebra** is a collection of subsets of X. All of the sets that can be assigned a measure (the measure returns a real number). The most common one is Borel´s. 

A measure is generally defined over a sigma algebra. 

A probability measure is a measure with an extra condition: 
- The values it gives back must be between [0,1]. 
- The measure of the whole set must be 1.

### Probability Space

- Triple $(\Omega, \mathcal{F}, \mathbb{P})$
- $\Omega$ is the sample space, or set of all possible outcomes of a random process under consideration.
- An event space or sigma algebra, $\mathcal{F}$, is a set of events, where an event is a subset of outcomes in the sample space.  
- A probability measure or function, $\mathbb{P}$, which assigns, to each event in a space, a probability, which is a number between 0 and 1 (inclusive).
