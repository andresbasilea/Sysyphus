
- Pricing of the cloud: 
	- AWS has 3 pricing fundamentals: 
		- Compute: pay for compute time
		- Storage: Pay for data stored in the cloud
		- Data transfer OUT of the cloud: Data transfer IN is free

**AWS Regions:** 
- Regions all around the world
	- A region is a cluster of data centers
	- Most services are region-scoped
	- us-east-1, eu-west-3
- How to choose a region? 
	- Compliance: with data governance and legal requirements
	- Proximity to customers
	- Available services
	- Pricing: varies from region to region

**AWS Availability Zones**:
- Each region has many availability zones (usually 3, max is 6)
- Each AZ is one or more discrete data centers with redundant power, networking and connectivity
- They are separate from each other (isolated)
- High bandwidth, ultra-low latency networking


**Shared Responsibility Model**: 
- Customer is responsible for security "IN" the cloud
- AWS responsible for security "OF" the cloud
