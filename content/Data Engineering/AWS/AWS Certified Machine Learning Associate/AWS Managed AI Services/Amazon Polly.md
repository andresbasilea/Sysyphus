- Turn text into lifelike speech using deep learning
- Allowing you to create apps that can talk

### Lexicons
- Define how to read certain specific pieces of text
	- AWS -> Amazon Web Services
	- W3C -> World Wide Web Consortium

### SSML - Speech Synthesis Markup Language
- Markup for your text to indicate how to pronounce it
- Hello \<break> how are you?

### Voice engine: 
- Generative (most expressive), long-form, neural, standard

### Speech mark: 
- Encode where a sentence/word starts or ends in the audio
- Helpful for lip-syncing or highlight words as they are spoken
